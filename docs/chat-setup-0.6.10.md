# Подключения и создание скиллов из чата

Проверено 5 октября 2026 года.

## Поведение

Модель получила `list_connectors`, `connect_connector` и `create_skill`. Они доступны в обычной сессии и субагентам; создание и подключение проходят через существующие разрешения, включая режим плана, отказ и остановку. Проверка наличия инструмента сама по себе больше не является тупиком: системная инструкция предлагает подготовить подключение для исходной задачи.

Пресеты Figma Remote и Desktop содержат проверенные адреса. Сохранённое подключение используется повторно, без сброса его авторизации. Новый сервер HTTP можно добавить по точному адресу; запуск нового stdio-сервера не маскируется под вход в сервис. Сохранённые stdio-коннекторы поддерживаются.

OAuth-карточка меняет состояние по событиям MCP. Успех означает завершённое согласование и обнаружение инструментов, а не только открытый браузер. Новые инструменты доступны модели на следующем шаге того же запроса. Повторный вход открывает только проверенную ожидающую OAuth-ссылку из основного процесса. Ссылка, код и токены не записываются в историю и не передаются модели.

Создание скилла показывает подготовленные инструкции и область. Проектный скилл назначается текущему проекту, личный доступен через `@имя`. Существующее имя с другим содержимым не перезаписывается; повтор идентичного создания не создаёт дубль. Отсутствующие локальные файлы справки и неподдерживаемые вложения отклоняются.

## Проверки

- 267 автоматических тестов прошли; один POSIX-тест пропущен на Windows. Проверены отказ, отмена OAuth, повторное подключение, отсутствие дубликатов, сохранность скиллов, продолжение с новыми инструментами и независимая отмена второго ожидающего чата.
- TypeScript и production-сборка интерфейса проходят. Остаётся прежнее предупреждение Vite о размере общего JS-файла.
- Готовый Windows EXE 0.6.10 успешно запущен с отдельным пустым профилем: renderer загружен, sandbox включён. Содержимое семи изменённых файлов Electron в ASAR совпадает с исходниками; версия и SHA-256 сохранены в `package-integrity.json` рядом с отчётами.
- В скрытом Electron с отдельным профилем пройден сценарий: карточка, подтверждение, OAuth, повторное открытие входа, настоящий локальный callback, обнаружение и вызов тестового MCP-инструмента, итоговый ответ. Также проверены создание/назначение/загрузка скилла, ошибка сервера и повтор из карточки.
- Проверены обе темы, узкое окно, отсутствие ошибок renderer и отсутствие OAuth-секретов в истории. Отчёт и снимки: `Artifacts/turwe-code/chat-setup-0.6.10/ui-report.json` относительно родительской рабочей папки.
- Два коротких синтетических запроса через `claude-opus-5-5` подтвердили выбор `connect_connector` с пресетом Figma и `create_skill` с валидным SKILL.md. Пользовательская история и файлы в эту проверку не отправлялись. Эти запросы проверяют выбор инструмента, а не вход в настоящий аккаунт.

## Границы проверки

Реальный OAuth-вход в аккаунт пользователя Figma не выполнялся. По [актуальной документации Figma](https://developers.figma.com/docs/figma-mcp-server/) удалённый сервер допускает только клиенты из каталога. Одобрение Turwe со стороны Figma этим обновлением не предоставляется. Есть готовый переход на [локальный MCP Figma Desktop](https://developers.figma.com/docs/figma-mcp-server/local-server-installation/); сервер нужно включить в Figma, его инструменты могут отличаться от Remote.

Для новых сервисов без OAuth или с особой регистрацией могут потребоваться данные провайдера. Приложение не выдумывает адреса и не обходит права сервиса. Ключи bearer вводятся в защищённых настройках, не в обычном сообщении.

Программные изменения общие для Windows и macOS; нативная проверка этого выпуска выполнена на Windows. Сборка macOS требует соответствующей машины.
