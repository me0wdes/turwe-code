# Turwe Code 0.3.0 — проверка 4 октября 2026

## Реализовано

- Импорт публичных GitHub-скиллов из чата и библиотеки: выбор SKILL.md, закрепление коммита, текстовые справки, индивидуальное назначение проекту, отсутствие скрытой перезаписи.
- Вложения через меню «+», Ctrl+V, drag/drop и буфер: постоянные копии, предпросмотр, сохранённые черновики; реальные изображения и текст документов в API. Видео передаётся выбранными кадрами с временными отметками.
- MCP SDK: Streamable HTTP, stdio, OAuth/PKCE и обновление токенов, шифрование Windows, карточки подключения, Figma Desktop/Remote, вызов инструментов моделью и явные разрешения на операции без readOnly.
- Редактирование и повтор ответа через новую ветку, Markdown-экспорт, чтение файлов выбранного проекта. Снимки инструкций и завершённые вызовы инструментов сохраняются при повторе после ошибки.

- TypeScript и Vite build: успешно. Неблокирующее предупреждение Vite о размере JS-bundle остаётся.
- `npm audit --omit=dev`: у runtime-зависимостей нет опубликованных уязвимостей на момент проверки.
- Реальный `ai.lab.pics/v1`, `claude-opus-5-5`: тестовая красная PNG → `Red`, HTTP 200; echo tool → аргумент `TURWE_TOOL_OK` → ответ `TOOL_OK`, оба HTTP 200. Использован сохранённый Windows-ключ; реальные файлы пользователя в тест не отправлялись. Отчёт `Artifacts/turwe-code/capabilities-0.3.0/provider.json`.
- GitHub: реальное чтение `anthropics/skills`, 20 кандидатов; проверка установки frontend-design в изолированное хранилище в памяти, включая целостность blob. Рабочая библиотека пользователя не менялась.
- Electron 44.5.1: в отдельном профиле прочитаны настоящие PNG, PDF, DOCX, MP4; результат — две картинки и два текстовых документа, предпросмотр работает. Отчёт `native/native-probe.json`.

- CUA: меню вложений, форма GitHub, сохранение карточки MCP, переключение HTTP/stdio и меню авторизации. Окно MCP сохраняет размер 510×620; при 800×620 — 510×560, прокрутка внутри, нет горизонтального переполнения или нативных select. Консоль без ошибок/предупреждений. Временная вкладка закрыта, viewport сброшен.

Первый архив был повреждён изменением исходников во время упаковки. Он заменён повторной сборкой из неизменяемых файлов, с проверкой целостности и успешным запуском. Последний файл — `release/Turwe-Code-0.3.0-Windows.exe`.

## Практические ограничения

- Figma Desktop `127.0.0.1:3845` на этом компьютере не отвечал. Включение сервера в Figma и последующее подключение остаются действиями пользователя. Удалённая авторизация реального аккаунта Figma не выполнялась; Figma может ограничивать Remote поддерживаемыми клиентами. SDK OAuth проверен локальным сервером.
- PDF/DOCX — извлечённый текст, без OCR, встроенных изображений и вёрстки. Видео — до восьми кадров без звука; события между кадрами могут быть пропущены.
- GitHub — публичные репозитории; исполняемые/динамические скиллы и отдельные агенты по-прежнему отмечаются как несовместимые. Встроенного произвольного shell, голосового режима и браузерного поиска нет.
- Native Windows DROPFILES-парсер проверен на Unicode/ANSI/ошибках. Наличие CF_HDROP в строковых форматах Electron зависит от источника буфера; предусмотрен FileNameW, а обычная вставка файлов использует ClipboardEvent.files.

[Референсы интерфейса — Lazyweb](https://www.lazyweb.com/agentic-search/6bb4bafd-984a-4194-936b-eada6a0bd235). Секретные одноразовые URL исследования не записаны в артефакты.
