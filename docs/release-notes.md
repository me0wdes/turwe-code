Turwe Code для Windows и macOS.

## Что изменилось в 0.6.18

- **Разрешения на весь проект и навсегда.** В карточке действия откройте «Всегда разрешать…»: выбранный инструмент можно разрешить для всех чатов проекта либо для всех проектов. Разрешение сохраняется после перезапуска. В «Доступ и LSP» его можно отозвать. Разовое подтверждение и запоминание точного вызова тоже доступны. При выборе постоянной области ручной режим переключается в упрощённый; меню сообщает об этом заранее.
- **Четыре режима действий.** Ручной спрашивает каждый раз; упрощённый использует ваши сохранённые разрешения; авто отправляет остальные действия отдельной модели для проверки; «Ебашим на все бабки» отключает проверки разрешений приложения. Модель проверки выбирается в настройках, автоматически предпочитается Haiku, затем Sonnet. Решение модели не сохраняется как постоянное разрешение.
- **Новая сессия без пустых чатов.** Отдельный стартовый экран позволяет выбрать проект или начать разговор без него. Рабочая папка в «Документы/Turwe/Projects» создаётся при необходимости сохранить файлы. Контекст из других папок доступен через файловые инструменты с учётом разрешений.
- **Создание папки на Mac.** В системном окне выбора проекта включено создание новой папки.
- **Figma MCP.** Исправлен выбор OAuth-метода по метаданным сервера. Ошибки теперь различают регистрацию, авторизацию и недоступный локальный сервер. Отказ Figma в регистрации Turwe не выдаётся за неправильные права пользователя; обход внешнего ограничения не заявляется.
- **Плавные виджеты.** Открытие и закрытие правых панелей повторяют анимацию левой колонки. Добавление второй панели и смена расположения плавно перестраивают область. Учитываются отключение анимаций и системное уменьшение движения; встроенный браузер возвращается с правильными размерами после перехода.

Проверены 316 автоматических сценариев на Windows; один POSIX-сценарий пропущен. Интерфейс, разрешения, файловые вызовы, анимации и встроенный браузер проверены в Electron на отдельном профиле. Сборки всех платформ проходят отдельный запуск перед публикацией.

## Скачать

- **Windows 10/11, x64:** файл `Windows.exe`. Переносимая версия, установка не нужна.
- **Mac с Apple Silicon (M1 и новее):** `macOS-arm64.dmg`.
- **Mac с Intel:** `macOS-x64.dmg`.

На Mac откройте DMG и перенесите Turwe Code в Applications. ZIP — альтернативный архив приложения. Файлы «Source code» предназначены для разработчиков.

Ручная проверка обновлений: Настройки → Интерфейс → Обновления приложения. Кнопка «Скачать» открывает файл для вашей ОС и архитектуры. Перед заменой приложения закройте предыдущую версию. История и настройки хранятся отдельно и сохраняются.

Сборки пока без сертификата издателя Windows и Apple Developer ID/notarization. При первом запуске система может попросить подтверждение. На macOS разрешение для доверенного приложения доступно в Системные настройки → Конфиденциальность и безопасность.

Используется ваш API-ключ: в поставке нет чужих ключей или истории чатов. Контрольные суммы всех сборок — в `SHA256SUMS.txt`.
