## Интерактивная проверка

Использован Codex In-app Browser через CUA, без внешнего Playwright/CDP. Браузерный режим явно помечен «Браузерный просмотр»; он не получает ключ и не изображает работу с настоящим диском или API.

- Созданы две сессии, в каждой введён свой черновик. Переключение и перезагрузка сохраняют независимый текст.
- Сессия переименована; поиск по содержимому через Ctrl+K находит её. Ctrl+N создаёт новую сессию.
- Архивирование скрывает сессию из активного списка; в архиве сохраняется черновик, ввод отключён до восстановления. Восстановление возвращает тот же текст.
- Настройки звука и движения выключены, сохранены и проверены после перезагрузки. Кнопка прослушивания отключена при выключенном звуке. Затем звук и движение возвращены.
- Громкость изменена клавиатурой до 1%, после перезагрузки сохранилась; возвращена к 20%. По четыре повторных переключения звука и анимаций не заблокировали управление.
- Проверены открытие и закрытие панели файлов, её поведение в окне 800×620. Узкое окно использует панель поверх рабочей области. Переход появления и исчезновения задан через Motion; после закрытия основной интерфейс доступен.
- В журнале проверенного браузерного интерфейса ошибок JavaScript нет.
- Реальное чтение каталогов и файлов, отказ при выходе из папки проекта, история, повтор, отмена и конкуренция проверены Node-тестами backend-модулей. Это не объявляется проверкой системного диалога мышью.

Системный выбор папки, ручное изменение размера нативного окна и субъективное звучание аудио не проверялись через управление Windows: в этой среде нативное управление отключено. Синтез звука, ограничение частоты, громкость, отсутствие успеха при ошибке/отмене проверены кодом; состояния настроек — в браузере. Высота текста меняется сразу при вводе, чтобы не задерживать набор; движение панелей, выделения и уведомлений использует 80/160/240 мс и настройки reduced motion.

## Независимый просмотр кода

Выполнен отдельный просмотр исходников по утверждённой спецификации. Исправлены все найденные замечания:

1. Одновременный запуск двух окон мог перезаписать историю — добавлена блокировка одного экземпляра и тест реального повторного запуска.
2. Новый черновик мог стираться при завершении подготовки предыдущей отправки — введена условная очистка совпадающего текста и блокировка ввода на короткое время подготовки; регрессия покрыта тестом.
3. Первый фрагмент потока мог не попасть на диск при зависшем следующем фрагменте — первый фрагмент сохраняется сразу, последующие изменения сбрасываются по таймеру; добавлен тест.
4. Некорректный UTF-8 мог тихо заменяться символами — включено строгое декодирование и добавлен тест.
5. Настройки не показывали обнаруженные модели — теперь получают фактический список API.

Дополнительно статус остановленной сессии показывается как «Остановлена», а не «Завершена».
