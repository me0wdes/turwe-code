# Контекст и инструменты агента · 0.6.9

Проверено 5 октября 2026 года. Turwe использует собственный цикл выполнения инструментов через OpenAI-совместимый Chat Completions API. Параметр `claude_code` из Agent SDK сам по себе не включает функции Claude Code на этом API.

## Что получает модель

Путь выбранной папки или worktree, ОС и оболочку, до 80 имён файлов/каталогов верхнего уровня, до четырёх описаний README/PROJECT/ПРОЕКТ (не более 24 КБ суммарно), инструкции и память проекта. Описания содержат пометку о сокращении, если не поместились. Произвольные файлы проекта остаются доступны через инструменты, а не передаются целиком в каждый запрос. Ссылки наружу и файлы с несколькими жёсткими ссылками автоматически не читаются. Отказ в чтении или режим «Спрашивать» не обходится фоновым чтением описаний.

Для запроса о сервере агент получает указание сначала использовать описание проекта, затем прочитать относящиеся к подключению документы, проверить SSH реальной командой и сообщить фактический результат. Приватный ключ используется локальным SSH-клиентом; его содержимое не нужно передавать модели. Подтверждения команд продолжают зависеть от выбранного режима.

## Исправленные ошибки

- Русский вывод PowerShell декодировался неверно, а код возврата внешней программы мог заменяться на 1. Теперь вывод UTF-8, код сохранён, ошибки представлены обычным текстом без CLIXML.
- Неуспешная команда и таймаут попадали в журнал как успешно выполненный инструмент. Теперь результат содержит `isError`, статус, код возврата и пометку таймаута.
- `Process stop` возвращал результат до завершения асинхронной остановки. Теперь ожидается остановка. Неверная операция Process/Memory отклоняется до действия.
- Вывод процесса мог обрезаться посреди JSON. В ответе инструмента передаётся ограниченный хвост с пометкой сокращения; полный буфер процесса остаётся доступен в рабочей панели.
- Grep пропускал файлы из `.gitignore`, хотя Glob показывал их. Теперь оба ищут и в локальных файлах, сохраняя явные исключения для зависимостей, ключей и `.env`.
- `isError` от поискового MCP игнорировался. Теперь такой ответ становится ошибкой инструмента, а не поисковым источником.
- Последнее allow-правило могло перекрыть ask. Теперь ask имеет приоритет.
- `length`/`max_tokens`, `content_filter`/`refusal` и переполнение контекста не считаются успешным финалом. `tool_calls` без параметров — ошибка протокола.

## Границы совместимости

Это собственный агент Turwe, использующий опубликованные подходы. Исходники ядра Claude Code CLI не опубликованы в его официальном репозитории под открытой лицензией. [CLI](https://github.com/anthropics/claude-code/blob/main/LICENSE.md) и [TypeScript Agent SDK](https://github.com/anthropics/claude-agent-sdk-typescript/blob/main/LICENSE.md) указывают коммерческие условия. [Python SDK](https://github.com/anthropics/claude-agent-sdk-python/blob/main/LICENSE) имеет MIT-лицензию, но его транспорт запускает Claude Code CLI, а не реализует все его инструменты.

`pause_turn` относится к серверным инструментам Anthropic Messages API и требует сохранения полного ответа этого протокола. Текущий Chat Completions-коннектор не содержит такого адаптера: если шлюз присылает эту причину, показывается конкретная ошибка вместо ложного завершения. WebSearch в Turwe выполняется локальным клиентом через Exa MCP.

«Авто» в Turwe использует правила и признаки инструментов; отдельного классификатора разрешений Anthropic здесь нет. Shell запускается с правами пользователя ОС. Промпт и worktree не являются системной песочницей.

Регрессионные тесты находятся в `tests/project-context-tools.test.cjs`, `tests/tools-api.test.cjs` и `tests/platform-runtime.test.cjs`. Проверяются первый запрос и обновление контекста, worktree, ограничения чтения, настоящие локальные процессы, ошибки и отмена, поиск, приоритет разрешений и JSON/SSE-ответы API.
