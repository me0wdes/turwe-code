# Субагенты Turwe
Пользователь хочет настоящих субагентов через свой API и компактный виджет работы основного агента и его помощников, как в Claude Code. Сохраняем серую палитру, округлённые внутренние элементы, Mishanaer и Fluid motion.

В движке появляется инструмент delegate_tasks с массивом 1–3 независимых задач (title, task, optional model). Основной агент вызывает его сам при полезном разделении работы либо по прямой просьбе. Каждая задача получает отдельную историю и API-запросы, выбранный проект, вложения и снимок скиллов родителя. Результаты возвращаются инструментом после завершения всей группы, затем родитель составляет общий ответ. Дочерний агент может делегировать ещё один уровень. Всего до 6 субагентов на ответ, глубина 2, до 3 одновременных запросов субагентов. Ожидание потомков не занимает слот API, поэтому вложенность не вызывает deadlock.

Один существующий controller выполняет и основную сессию, и вложенные AgentRun с session-подобной структурой. Агентные записи хранятся внутри Message.agents и не засоряют список чатов. Время, дерево, ответы и инструментальные действия переживают перезапуск; незавершённое помечается остановленным. Повтор ответа сохраняет уже выполненные действия и результаты детей.

Режим подтверждений наследуется от главной сессии динамически. Вопросы и разрешения детей адресуются отдельным agentId в пределах rootSessionId, даже при одинаковых provider call IDs. «Стоп» главного ответа отменяет всё дерево и очередь. Отдельная остановка отменяет только выбранный подграф. Ошибка ребёнка возвращает явную ошибку и частичный результат, не выдуманный успех.

Над composer появляется сворачиваемый виджет: основной агент, вложенные строки задач, реальное текущее действие, пульсация только во время работы, жёлтая точка для ответа/разрешения. Строка открывает панель с задачей, моделью, выводом и инструментами, где можно ответить, подтвердить или остановить. В старых сообщениях остаётся ссылка на сохранённый запуск. Переключатель «Субагенты» в настройках управляет будущим делегированием; выключение не уничтожает историю.

API остаётся OpenAI-compatible /chat/completions с тем же ключом; отдельный Anthropic runtime не требуется. Субагенты расходуют отдельные запросы этого API. Доступны только уже реализованные инструменты, без обещаний shell/редактирования файлов, которых в приложении нет.
