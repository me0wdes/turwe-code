# Следующий пакет обновлений

Последняя опубликованная версия: **0.6.17**.

Готово: **6 улучшений**. Пакет **0.6.18** подготовлен к автоматической публикации: пятое улучшение завершено вместе с поступившим следом исправлением разрешений. Следующий отсчёт начинается после успешного выпуска всех платформ.

Готово локально:

1. **Режимы разрешений.** Ручной спрашивает каждый раз; упрощённый использует сохранённые человеческие разрешения; авто проверяет остальные действия отдельной моделью; «Ебашим на все бабки» пропускает проверки разрешений приложения. Выбор модели проверки в настройках, отдельные разовые и запоминаемые подтверждения, сброс разрешений проекта, видимый ход и результат проверки в чате. Разрешения модели не попадают в сохранённые разрешения. Проверены остановка, смена режима, очереди, субагенты и восстановление настроек. Подробности: [проверка реализации](permissions-verification.md).
2. **Создание папки проекта на macOS.** В системном окне выбора папки включена кнопка создания новой папки через `createDirectory`; подписи в выборе проекта теперь говорят «Выбрать или создать папку…». Поведение нативного окна сверено с [документацией Electron](https://www.electronjs.org/docs/latest/api/dialog). Проверены синтаксис, сборка и 7 существующих тестов запуска приложения и создания сессий; само окно macOS на Windows не проверялось. [Поиск референсов](https://www.lazyweb.com/agentic-search/343f4ba3-3238-455c-8b44-914134a2cde4): подходящих примеров нативного диалога не найдено, использован стандартный механизм macOS.

3. **Новый старт чата и рабочая папка.** «Новая сессия» открывает отдельный экран с выбором проекта и возможностью сразу начать чат. До первого сообщения история не пополняется; повторные нажатия не создают пустых сессий. Для рабочих файлов агент может создать отдельную папку в «Документы/Turwe/Projects» через CreateWorkspace, а FileWrite создаёт её автоматически при первой записи. FileRead/Glob/Grep читают нужный контекст из других папок с учётом разрешений, внешние файлы показываются в редакторе только для чтения. Субагенты используют рабочую папку основного чата. Проверены сохранение и откат файлов, разрешения, 303 теста (1 POSIX-тест пропущен на Windows), сборка, реальные вызовы через Electron на тестовом профиле и обе темы в Chromium. Нативная macOS пока не проверена. [Референсы стартового экрана](https://www.lazyweb.com/agentic-search/18d747a7-a80d-4ad5-b1d3-45e37d3745ef).

4. **Подключение Figma MCP и диагностика OAuth.** Способ регистрации OAuth выбирается по метаданным сервера вместо принудительного `none`. Карточка и агент получают фактический этап и HTTP-код ошибки; сетевые ошибки больше не выдаются за требование одобрения клиента. Для выключенного Desktop указаны точные шаги включения локального MCP. Тип подключения определяется URL, даже если удалённый сервер назван «Figma Desktop»; прямой локальный URL по умолчанию не запускает OAuth. Проверены 311 тестов (1 POSIX-тест пропущен), сборка и настоящие ответы Figma через Electron: Remote возвращает HTTP 403 на регистрации Turwe, локальный сервер сейчас не принимает соединение. Это внешние ограничения, успешный доступ к аккаунту не заявляется. [Подробности проверки](mcp-connection-verification.md).

5. **Плавное раскрытие виджетов.** Правая область раскрывается и закрывается той же пружиной, что левая панель. Две панели плавно меняют размер и расположение. Проверены промежуточные кадры, быстрое закрытие/повторное открытие, reduced motion, размеры нативного браузера. [Референс](https://www.lazyweb.com/agentic-search/cb56a37a-9161-4bda-aae1-4089eeeb6407).

6. **Постоянное разрешение на инструмент.** В карточке действия доступны области «Всегда в этом проекте» и «Всегда во всех проектах». Разрешения переживают перезапуск; их можно независимо отозвать в «Доступ и LSP». Меню объясняет область и переход ручного режима в упрощённый. Проверены разные параметры, другие проекты/worktree, смена MCP, ручной режим, запреты, отмена, сохранение и отзыв через настоящий интерфейс Electron.

Подробности пакета: [описание 0.6.18](release-notes.md), [проверка разрешений](permissions-verification.md).
