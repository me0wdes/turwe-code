## Границы проверки

Генерация ответов использовала mock API. Фактическая поддержка `reasoning_effort` и tool calling зависит от модели/шлюза. Реальные PR, push и удалённый CI не запускались; для них нужны репозиторий, GitHub CLI и авторизация. Git/Bash/gh и серверы других языков — внешние зависимости. JS/TS LSP, ripgrep и PTY упакованы в приложение.

Сборка использует готовые N-API бинарники node-pty, проверенные в packaged Electron; `npmRebuild:false` исключает ненужную пересборку с требованием Visual Studio. При обновлении node-pty/Electron повторяйте нативный smoke-тест. Vite сообщает об основном JS bundle больше 500 КБ; это предупреждение размера, сборку не блокирует.

Реализации используют открытые зависимости с лицензиями. Адаптации OpenCode перечислены в `THIRD_PARTY_NOTICES.md`; проприетарные внутренние исходники Claude Code не копировались.
