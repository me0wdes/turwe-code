# Turwe Code 0.3.1 — проверка взаимодействий

Дата: 4 октября 2026.

## Изменения

- Строки чатов: 32 px + 2 px промежуток вместо 39 px + 3 px. Пустые, завершённые, остановленные и ошибочные чаты без постоянной точки. Активная работа — пульсирующая нейтральная точка; ожидание разрешения или ответа — статичная жёлтая. Настройка уменьшения движения отключает пульсацию.
- Режим внизу композера сохраняется отдельно для чата. `ask`: каждый инструмент требует подтверждения; `auto`: объявленные чтения разрешены, изменения/неизвестные операции запрашивают разрешение; `bypass`: доступные инструменты выполняются без подтверждений. При смене режима ожидающее разрешение пересматривается. Ветки наследуют режим, новый чат начинает с `auto`.
- Инструмент `ask_user`: от 1 до 3 вопросов с вариантами, множественным выбором, свободным текстом и явным пропуском. Пошаговая карточка, ответы сохраняются в истории и возвращаются в модель в сообщении инструмента. Bypass не отвечает на вопросы. Черновые ответы сохраняются при навигации между чатами до закрытия приложения.
- Остановка и перезапуск не оставляют фиктивное ожидание. Ответ, после которого сразу нажата остановка, сохраняется; следующий запрос модели не запускается. Повторный или устаревший ответ отклоняется.

В Turwe используется описанная локальная политика, без классификатора Anthropic. Официальные режимы Claude проверены по [документации](https://code.claude.com/docs/en/permission-modes); полное совпадение движков не заявляется.
