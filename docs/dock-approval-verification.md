# Проверка панелей и постоянных разрешений · 0.6.18

Проверено на Windows в настоящем Electron с отдельным профилем. Для UI использован Playwright Electron: профильный browser-плагин в этой среде не установлен. Пользовательские чаты, ключи и файлы не затрагивались.

- Записаны размеры каждого кадра при раскрытии и закрытии области, добавлении и удалении второго виджета, перестроении в колонки. Есть промежуточные размеры, а не мгновенный скачок. Быстрое закрытие и повторное открытие не оставляют невидимый или неактивный виджет.
- Использована существующая пружина `fluid.slow` из SidebarRail. Системное уменьшение движения выключает анимацию. Текст панели держит конечную ширину, пока раскрывается внешняя область.
- Проверены обе темы, узкое окно с перекрывающей панелью и отключённая настройка анимаций приложения. Горизонтальная прокрутка окна не появляется.
- Локальная страница загружена в настоящий WebContentsView. После перестроения двух панелей его границы совпадают с поверхностью браузера, после закрытия нативное содержимое скрывается.
- Вызовы FileRead проходят через настоящий IPC, контроллер и файловый инструмент. Имитируется только ответ внешнего API. Постоянное разрешение проекта допускает следующий файл с другими аргументами; ручной режим явно меняется на упрощённый.
- Через «Доступ и LSP» отдельно отозваны разрешения проекта и всех проектов. Счётчики реагируют на новые разрешения в открытой панели. После отзыва возвращается запрос, отказ не запускает чтение.
- Автоматические проверки отдельно покрывают сохранение после перезапуска, другие проекты и worktree, изменение идентичности инструмента/MCP, правила запрета и отмену до выполнения. В пакете: 317 тестов, 316 пройдено, 1 POSIX-тест пропущен на Windows.

Артефакты локальной проверки: `Artifacts/turwe-code/dock-approvals-report.json` и одноимённая папка скриншотов вне репозитория. Поиск [Lazyweb](https://www.lazyweb.com/agentic-search/cb56a37a-9161-4bda-aae1-4089eeeb6407) дал пример соседних рабочих областей; статичный референс не используется как доказательство параметров анимации. Для разрешений подходящих продуктовых экранов не найдено, использованы собственные компоненты Turwe.
