# Turwe Code: инструменты и этапы A–B–C

Запрос: реализовать весь перечисленный набор инструментов и этапы A–B–C презентации от 04.10.2026. Исключены usage, цены и финансовые лимиты; остаётся effort. Этап D не входит. Пользователь разрешил использовать подходящие открытые реализации.

## Архитектура

Сохраняем Electron/React и текущий OpenAI-compatible transport, историю, вложения, MCP и скиллы. Новые сервисы работают в main process; renderer получает только проверяемые команды через preload. Сервисы инструментов и панели используют один backend. Изменения файлов фиксируются до записи; shell честно исполняется с правами пользователя и не называется ОС-песочницей. Изоляция параллельных правок — Git worktree. Конфликты при восстановлении не затирают внешние изменения.

## Ограничения окружения

Git/gh/Bash и серверы языков кроме встроенного JS/TS обнаруживаются на компьютере; отсутствие показывается с понятным действием, а не фиктивным успехом. Для PR нужен вход в gh. Сетевые функции проверяются на fixture и доступных публичных данных; платные запросы по сохранённому ключу пользователя не нужны для проверки реализации. Внешний провайдер может не поддержать effort — запрос не должен молча скрывать ошибку.
